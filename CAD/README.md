# CAD Files

Place STL files for 3D printing here.

## Required Parts

| File | Description |
|------|-------------|
| `bottom_deck.stl` | Main chassis plate with motor mounts |
| `top_deck.stl` | Electronics mounting plate |
| `caster_mount.stl` | Rear caster wheel bracket |

## Print Settings

- **Material:** PLA or PETG
- **Layer height:** 0.2mm
- **Infill:** 20% (30% for caster mount)
- **Supports:** Only needed for caster mount
