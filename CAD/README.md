# CAD Files

STL files for 3D printing all the custom parts of the MERPY robot.

## Parts List

| File | Description | Qty |
|------|-------------|-----|
| `Merpy_base_plate.STL` | Bottom deck / main chassis plate | 1 |
| `Merpy_top_plate.STL` | Top deck / electronics mounting plate | 1 |
| `Merpy_left_TT_motor_mount.STL` | Left motor mount bracket | 1 |
| `Merpy_right_TT_motor_mount.STL` | Right motor mount bracket | 1 |
| `Merpy_on_off_switch_mount.STL` | Power switch mount | 1 |
| `Merpy_cam_mount.STL` | Camera mount bracket | 1 |
| `ESP32_cam_case.stl` | ESP32-CAM enclosure | 1 |

## Print Settings

- **Material:** PLA or PETG
- **Layer height:** 0.2mm
- **Infill:** 20% (30% for motor mounts)
- **Supports:** Check each part in your slicer, most print without supports
